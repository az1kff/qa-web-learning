# Путь в IT

Локальный практикум по QA и веб-разработке. 32 занятия, включая три контрольные работы. Пять входных задач, девять встроенных тренажёров и отдельный учебный HTTP-стенд.

## GitHub Pages

[Открыть практикум](https://az1kff.github.io/qa-web-learning/). Онлайн-стенд моделирует ответы API в браузере. Для задания с сетевыми запросами в DevTools нужен локальный запуск. Прогресс разных адресов хранится отдельно. Его можно перенести через экспорт и восстановление JSON.

## Запуск на Windows

1. Дважды щёлкни «Запустить.cmd».
2. Страница откроется на [127.0.0.1:4176](http://127.0.0.1:4176/). Окно сервера оставь открытым, пока работаешь со стендом.
3. Начни с диагностики или открой конкретный урок в «Маршруте».

Альтернатива для терминала — `node server.mjs` из папки проекта. Приложение проверено на Node.js 24. «Запустить.cmd» открывает отдельный браузерный профиль в папке `.profile` внутри проекта. Его файлы загрузки по умолчанию сохраняются в папку «Учебные-файлы» на D. Прогресс закреплён за браузерным профилем и адресом приложения. Экспортируй резервную копию через «Данные».

## Как устроена практика

- В каждом уроке есть пример, самостоятельное задание, подсказки, критерии и новое условие для повтора.
- Приложение автоматически проверяет структурированные упражнения, а свободный ответ сохраняется вместе с самопроверкой. Ревью можно записать отдельно в портфолио.
- На стенде переключай исправную форму и учебный дефект. В DevTools можно увидеть реальные запросы к локальному API.
- Для самостоятельного JavaScript скачай заготовку и тесты из «Материалов». Сохрани их в одной папке на D. Команда `node --test exercise.test.mjs` запускает тесты. Незаполненная заготовка даёт ожидаемые падения.
- Для SQL в той же папке можно запустить `node sql-practice.mjs`. Это настоящая SQLite с синтетическими данными в памяти. Для учебного репозитория в «Материалах» есть шаблон проверки PR.
- Для повторения приложение назначает следующий срок на 1, 3, 7 или 14 дней в зависимости от попытки.
- Если установить из поддерживающего браузера и дождаться первой загрузки, уроки, встроенные тренажёры и резервное копирование работают офлайн. HTTP-стенд требует запущенного сервера. Сервер доступен только с текущего компьютера.
- Интерфейс адаптивный. Для отдельного телефона нужен доступный ему HTTPS-хостинг приложения или другой согласованный способ подключения. Этот запуск рассчитан на один компьютер.

## Данные и источники

Черновики, попытки, повторения, портфолио и журнал откликов находятся в браузере. Ссылки на локальные файлы и внешние репозитории хранятся в тексте копии. Сохраняй сами файлы отдельно. Стенд использует вымышленные данные, которые сбрасываются при закрытии сервера.

Оригинальные уроки опираются на темы четырёх HTML «Инсайт чат» и шести недель QA Roadmap IT PUNK. Подробности в «ПЛАН-УЧЕБНОЙ-ПЛАТФОРМЫ.md» и на экране «Материалы».
